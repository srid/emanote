# External tools

Third-party tools that talk to your Emanote notebook — editors that author it, sync engines that replicate it, alternative notebook formats Emanote can read.

- **[[editors]]** — Vim, VS Code, Obsidian, Nota integrations
- **[[sync]]** — syncing notes across devices with Syncthing
- **[[zk]]** — running Emanote on a [zk](https://github.com/mickael-menu/zk) notebook
