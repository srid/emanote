# Configuration

The configuration surface — YAML files, layer mounts, ignore patterns, language toggles. Read this section before [[theme|theming]] or writing [[extend|extensions]]; both consume the surfaces defined here.

- **[[yaml-config]]** — site and per-note metadata, cascade rules
- **[[layer]]** — merging multiple notebook directories
- **[[emanoteignore]]** — excluding files from the notebook model
- **[[i18n]]** — internationalisation via `page.lang`

Notebook-model semantics that flow from authoring choices (folder notes, structural wikilinks) live under [[authoring]].
